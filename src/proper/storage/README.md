# proper.storage

This module makes it simple to upload and reference files locally or in cloud services like [Amazon S3](https://aws.amazon.com/s3/), [Google Cloud Storage](https://cloud.google.com/storage/docs/), [Microsoft Azure Storage](https://azure.microsoft.com/en-us/services/storage/), or any S3-Compatible Object Storage, like [DigitalOcean Spaces](https://www.digitalocean.com/products/spaces), and attach those files to your models.

Image files can furthermore be transformed using on-demand transformations, like resizing, cropping, watermarking, etc.
