# proper.storage

This module makes it simple to upload files locally or to cloud services - [Amazon S3](https://aws.amazon.com/s3/), [Google Cloud Storage](https://cloud.google.com/storage/docs/), [Microsoft Azure Storage](https://azure.microsoft.com/en-us/services/storage/), or any S3-compatible object storage like [DigitalOcean Spaces](https://www.digitalocean.com/products/spaces) - and attach them to your models.

Image files can also be transformed on demand: resizing, cropping, watermarking, and so on.
