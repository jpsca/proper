For the actual source code of any file, read the file directly from the app.

## Boot Sequence

The application boots when the package is imported. The order matters — each module depends on the previous ones:

```python
# myapp/__init__.py
from . import main          # 1. Create the App instance
from . import router        # 2. Set up the router and static routes
from . import controllers   # 3. Import controllers (registers routes via decorators)
from . import models        # 4. Import models (registers them for migrations)
from . import tasks         # 5. Import tasks (registers them with the queue)
```

This is why adding a new controller or model requires importing it in the respective `__init__.py`.


## Core Files

**`main.py`** — Creates the `App` instance from the config module. The `app` object is imported by nearly every other module.

**`router.py`** — Exports the `router` object from `app.router`. Defines the static file handler and root-level asset redirects (favicon, robots.txt, humans.txt). Controllers import `router` to register routes via decorators.

**`config/__init__.py`** — Imports config modules in order. Later modules can override values from earlier ones. All exported names become attributes of `app.config`.


## Configuration

**`config/main.py`** — Environment-aware core settings: `DEBUG`, `PROTOCOL`, `HOST`, `SECRET_KEYS`, `CATCH_ALL_ERRORS`, `MAX_CONTENT_LENGTH`, `MAX_QUERY_SIZE`, `MAX_FORM_FILES`, `MAX_FORM_FIELDS`, `MAX_FORM_PART_SIZE`, `ASSETS_URL`, `STATIC_X_SENDFILE_HEADER`, `MAILER`, `MAILER_DEFAULT_OPTIONS`.

**`config/session.py`** — Session cookie settings: `SESSION_COOKIE_LIFETIME` (30 days), `SESSION_COOKIE_DOMAIN`, `SESSION_COOKIE_PATH`, `SESSION_COOKIE_HTTPONLY`, `SESSION_COOKIE_SAMESITE`.

**`config/storage.py`** — Per-environment config for three subsystems:

| Subsystem | Dev | Test | Prod |
|-----------|-----|------|------|
| **DATABASES** | SQLite file | SQLite `:memory:` | PostgreSQL |
| **QUEUE** | `MemoryHuey` (immediate) | `MemoryHuey` (immediate) | `RedisHuey` |
| **CACHE** | `SqliteCache` (`:memory:`) | `NoCache` | `SqliteCache` (file) |


## Controllers

**`controllers/__init__.py`** — Every controller must be imported here for route registration.

**`controllers/app_controller.py`** — Base class for all controllers. Includes `Controller`, `OriginProtection`, `RateLimiting`, and `SecurityHeaders` by default. Add shared concerns (like `Authentication`) here.

**`controllers/public_controller.py`** — Handles error pages (`@router.error(errors.NotFound)`, `@router.error(Exception)`) with preview routes (`/_not_found`, `/_error`). Home page (`/`) is commented out — uncomment to enable. Has `skip_authentication = True`.

**`controllers/concerns/security_headers.py`** — Sets security response headers as an `after` callback: `X-Frame-Options`, `X-XSS-Protection`, `X-Download-Options`, `X-Permitted-Cross-Domain-Policies`, `Referrer-Policy`. Lives in the app (not the framework) so you can customize it.


## Models

**`models/__init__.py`** — Every model must be imported here for migration detection.

**`models/base.py`** — Defines `BaseModel` and `db` (raw database instance for `db.atomic()` transactions). All bind to `app.db["main"]`.

**`models/concerns/russian_doll_cached.py`** — Mixin that adds `updated_at` and a `touches` mechanism for cascading cache invalidation through `{% cache %}` template fragments.


## Templates

**`views/layouts/app.jx`** — Main HTML layout. Props: `title`, `description`, `lang`. Includes asset fingerprinting via `url_for('assets', ...)`, Turbo Drive, component asset collection (`assets.collect_css()`/`assets.collect_js()`), `<Nav />` and `<Flashes />` components, and `attrs.render()` on `<body>`.

**`views/form.jx`** — Reusable form component. Props: `action`, `method`, `multipart`, `novalidate`. Handles method override automatically — if method is not GET/POST, renders a hidden `_method` input and sets the form to POST.

**`views/flashes.jx`** — Renders flash messages from `current.request.flashes` as `(type, message)` tuples.

**`views/nav.jx`** — Empty by default. Updated by the auth addon to show sign-in/sign-out links.

Page-specific CSS is loaded using the `{#css "..." #}` directive in templates, which feeds into `assets.collect_css()` in the layout.


## Emails and Tasks

**`emails/base_email.py`** — All custom emails inherit from `BaseEmail` (extends `proper.EmailMessage`). Provides `send_later()` for background delivery via the task queue.

**`tasks/__init__.py`** — Contains the built-in `send_email_task` that calls `app.mailer.send_now()`. Add your own tasks here or in separate files within `tasks/`.


## CLI

**`cli/__init__.py`** — Entry point registered in `pyproject.toml` as `proper = "myapp.cli:run"`.

**`cli/app_cli.py`** — Overrides the `run` command to start the Tailwind CSS watcher as a subprocess before booting the dev server.


## Tests

**`tests/__init__.py`** — Sets `APP_ENV=test` before any app code is imported.

**`tests/conftest.py`** — Three fixtures: `client` (returns an instance of `proper.TestClient`), `db_setup` (session-scoped, creates/drops tables, calls `load_fixtures()`) and `dbs` (autouse, wraps every test in a rolled-back transaction). Safety-checks the database name contains `_test` or is `:memory:`.


## Server and Workers

**`uvicorn.dev.py`** — Dev config: `0.0.0.0:2300`, `reload=True`, large `timeout_keep_alive` for debugging.

**`uvicorn.py`** — Production config: `0.0.0.0:2300`, `timeout_keep_alive=30`, no reload.

**`workers.py`** — Starts a Huey consumer with `QUEUE_CONSUMER` settings. Run with `python workers.py`.

## Docker and Deployment

**`compose.yml`** — Builds from `Dockerfile.dev`, mounts project into `/app`, exposes ports 2300 (uvicorn) and 5678 (debugpy).

**`deploy/nginx.conf`** — Asset hash rewriting for cache busting, static file serving bypassing Python, proxy pass to uvicorn, static 500 fallback, commented-out SSL config.


## Generators

### Resource Generator

```
proper g resource NAME [attrs...] [--only=actions] [--exclude=actions] [--pk=name] [--singular] [--migration]
```

Creates model + controller + form + views + test scaffold. See [controllers.md](controllers.md#the-generated-controller) for the generated controller pattern and [models.md](models.md#generators) for field type syntax.

**Files created:**

| File | Purpose |
|------|---------|
| `models/{name}.py` | Peewee model |
| `controllers/{name}_controller.py` | CRUD controller with before callback for record loading |
| `forms/{name}.py` | Formidable form with `Meta.orm_cls` binding |
| `views/{name}/index.jx` | List page |
| `views/{name}/show.jx` | Detail page |
| `views/{name}/new.jx` | New form page |
| `views/{name}/edit.jx` | Edit form page |
| `views/{name}/form.jx` | Shared form fields component |
| `tests/test_{name}.py` | Test skeleton (one function per action, bodies are `pass`) |

**Files modified:** `controllers/__init__.py`, `models/__init__.py` (adds imports)


### Controller Generator

```
proper g controller NAME [attrs...] [--only=actions] [--exclude=actions] [--namespace=NS_NAME] [--pk=name] [--singular]
```

Creates controller + form + views + test scaffold — **without** a model. Use when the model already exists or when no model is needed. See [controllers.md](controllers.md#namespacing-controllers) for namespace details.

**Files created:**

| File | Purpose |
|------|---------|
| `controllers/{name}_controller.py` | CRUD controller with before callback for record loading |
| `forms/{name}.py` | Formidable form (no `Meta.orm_cls` — not tied to a model) |
| `views/{name}/index.jx` | List page |
| `views/{name}/show.jx` | Detail page |
| `views/{name}/new.jx` | New form page |
| `views/{name}/edit.jx` | Edit form page |
| `views/{name}/form.jx` | Shared form fields component |
| `tests/test_{name}.py` | Test skeleton (one function per action, bodies are `pass`) |

**Files modified:** `controllers/__init__.py` (adds import)

**With `--namespace`:** files go into subfolders (e.g., `controllers/admin/`, `forms/admin/`, `views/admin/`). A scoped router is added to `router.py`.


### Model Generator

```
proper g model NAME [field_name[:type][,option[:value]]...] [--migration]
```

Creates a Peewee model file. See [models.md](models.md#generators) for field types, options, and foreign key syntax.

**Files created:** `models/{name}.py`

**Files modified:** `models/__init__.py` (adds import)

forms/auth/validators.py                    # Login/password validators and error messages
forms/auth/pwned.py                         # "Have I Been Pwned?" API integration

forms/sign_up.py                            # Registration form
forms/password_reset.py                     # Password reset + change forms
emails/password_reset_email.py              # Password reset email

- `controllers/__init__.py` — adds `SessionController`, `SignUpController`, `PasswordResetController`
- `controllers/app_controller.py` — adds `Authentication` to base class
- `models/__init__.py` — adds `User`, `Session`
- `emails/__init__.py` — adds `PasswordResetEmail`
- `cli/__init__.py` — adds `auth_cli`
- `views/nav.jx` — adds sign-in/sign-out links based on `current.user`
- `pyproject.toml` — adds `passlib`, `argon2-cffi`, `confusable-homoglyphs`

## Adding to the App

| What you're adding | Files to create | Files to modify |
|---|---|---|
| **Model** | `models/thing.py` | `models/__init__.py` (add import) |
| **Controller** | `controllers/thing_controller.py` | `controllers/__init__.py` (add import) |
| **Resource** | model + controller + form + views | `models/__init__.py`, `controllers/__init__.py` |
| **Concern (controller)** | `controllers/concerns/my_concern.py` | `app_controller.py` or specific controller |
| **Concern (model)** | `models/concerns/my_mixin.py` | Specific model |
| **Background task** | `tasks/my_task.py` or add to `tasks/__init__.py` | — |
| **Email** | `emails/my_email.py`, `views/emails/my_email.jx` | — |
| **Config module** | `config/my_config.py` | `config/__init__.py` (add import) |
| **Channel** | `channels/my_channel.py` | `controllers/__init__.py` (add import) |

The generator commands (`proper g resource`, `proper g model`) handle imports automatically.


## Generator Quick Reference

### Resource Generator

```
proper g resource NAME [attrs...] [--only=actions] [--exclude=actions] [--pk=name] [--singular] [--migration]
```

Creates: model, controller, form, views (index/show/new/edit/form), test skeleton.
Modifies: `controllers/__init__.py`, `models/__init__.py` (adds imports).

### Controller Generator

```
proper g controller NAME [attrs...] [--only=actions] [--exclude=actions] [--namespace=NS_NAME] [--pk=name] [--singular]
```

Creates: controller, form, views (index/show/new/edit/form), test skeleton. Does **not** create a model.
Use when the model already exists or when no model is needed.
With `--namespace`, files go into subfolders (e.g., `controllers/admin/`, `forms/admin/`, `views/admin/`).
Modifies: `controllers/__init__.py` (adds import).

### Model Generator

```
proper g model NAME [field_name[:type][,option[:value]]...] [--migration]
```

**Field types:** str (CharField), text (TextField), int (IntegerField), bigint (BigIntegerField), float (FloatField), decimal (DecimalField), bool (BooleanField), date (DateField), datetime (DateTimeField), time (TimeField), uuid (UUIDField), blob (BlobField), fk (ForeignKeyField).

**Options** appended with commas: `title:str,unique,index`, `views:int,default:0`, `user:fk-User,backref:tweets,on_delete:CASCADE`.


## Implicit Behaviors

- Test `conftest.py` wraps every test in a rolled-back transaction — tests are isolated automatically
- Config values in `config/storage.py` vary by `APP_ENV` (development/test/production)
- SQLite in dev/test, PostgreSQL in production (by default)
- `MemoryHuey` in dev/test (tasks run immediately), `RedisHuey` in production
